Clasificador de arritmias ECG

Clasifica cada latido como normal (N), supraventricular (S) o ventricular (V), con evaluación inter-paciente sobre MIT-BIH.

No es un dispositivo médico. Proyecto educativo y de investigación. No debe usarse para decisiones clínicas; toda salida requiere revisión de un profesional.

Probar la API

Genera en tu navegador una señal sintética de 30 segundos a 360 Hz y se la manda a POST /predict. Sirve para comprobar que la API responde de punta a punta; no es un ECG real, así que las predicciones son casi todas normales.

Endpoints

RutaQué hace
GET /docsDocumentación interactiva, con ejemplos ejecutables
GET /healthEstado del servicio y si el modelo está cargado
GET /modelVersión, clases, clases fuera de alcance y derivación
POST /predictClasifica los latidos de una señal

Desde la terminal

curl -s localhost:8000/model | python3 -m json.tool

curl -s -X POST localhost:8000/predict \
  -H 'content-type: application/json' \
  -d '{"fs": 360, "signal": [0.1, 0.2, "…"], "r_peaks": [370, 662]}'

Si no mandás r_peaks, se detectan solos. Si fs no es 360 Hz, la señal se remuestrea y la respuesta lo avisa.

Qué valida antes de predecir

ControlRespuesta
Frecuencia de muestreo fuera de 100–2000 HzRechaza con 422
Señal de menos de 10 s, vacía o con valores no numéricosRechaza con 422
Picos R desordenados, repetidos o fuera de la señalRechaza con 422
Ritmo muy irregular o frecuencia fuera del rango de entrenamientoAvisa en warnings
Calidad de señal baja o muy pocos latidosAvisa en warnings

Estas validaciones son controles de riesgo documentados, no cortesía: cada una está trazada a un requisito y a un riesgo.

Fuera de alcance: uso clínico, tiempo real, pacientes con marcapasos, pediatría y latidos de fusión (clase F). El modelo asume un ritmo de base regular.
